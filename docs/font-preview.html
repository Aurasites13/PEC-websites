PEC — Font Pairing Preview

Internal working page, not part of the public site (noindex, unlinked). Three licensed Google Fonts pairings — each one EN headline + EN body + JP headline + JP body — evaluated against the brief: European, elegant, modern, easy to read, and a “touch of Ralph Lauren.” All fonts below are open-licensed (SIL OFL / Apache), free for commercial web use.

The live site currently implements Pairing 2 — Fashion House, set via --font-display / --font-body / --font-display-ja / --font-body-ja in css/style.css. Swapping the whole site to a different pairing from this page means changing those four variables' values (and the Google Fonts <link> in every page's <head> to only load the fonts actually used) — see the note at the bottom of this page.

Recommendation: Pairing 2 — Fashion House

Bodoni Moda's high-contrast, vertical-stress letterforms are the closest thing in web type to the "fashion-house serif" register the brief asked for — it's the same family of shape that reads as Vogue / fashion-editorial / Ralph Lauren-adjacent without copying any brand's actual wordmark. Manrope keeps body copy calm, geometric, and European rather than competing with the headline. Shippori Mincho carries the same quiet elegance into Japanese without tipping into traditional-formal (ceremony/calligraphy) territory, and Noto Sans JP keeps body text neutral and highly legible at small sizes, which matters more for JP body copy than character.

This is the pairing implemented across the live redesign. It's easy to switch — see below.

To switch the whole site to a different pairing: in css/style.css, change the values of --font-display, --font-display-ja, --font-body, and --font-body-ja under :root to the chosen pairing's font names, then update the Google Fonts <link href="https://fonts.googleapis.com/css2?family=..."> in every page's <head> to request only those four families (to avoid loading unused font weights). No other code changes needed — every page reads type through those four variables.
