Internal working page, not part of the public site (noindex, unlinked). Three licensed Google Fonts pairings, each one EN title + EN body + JA title + JA body, evaluated against the brief: friendlier, more personable, with real character, while staying easy to read for parents and polished enough to still feel trustworthy. All fonts below are open-licensed (SIL OFL), free for commercial web use.

The live site currently implements Pairing 1: Cheerful Classic, set via --font-display / --font-body / --font-display-ja / --font-body-ja in css/style.css. Swapping the whole site to a different pairing from this page means changing those four variables and the Google Fonts <link> in every page's <head> to request only the families actually used, see the note at the bottom of this page.

Recommendation: Pairing 1, Cheerful Classic

Fraunces is a soft, rounded-but-serious display serif: it has real warmth and a hint of playfulness in its curves (unlike a formal fashion-house serif) without tipping into a childish or novelty typeface, so it still reads as a legitimate education brand to the parents who are paying. Nunito's rounded terminals keep body copy approachable and easy to read at small sizes. Zen Maru Gothic gives Japanese titles the same rounded, friendly energy, and Zen Kaku Gothic New keeps Japanese body copy clean and highly legible, which matters more for body text than character.

This is the pairing implemented across the live redesign. It is easy to switch; see below.

To switch the whole site to a different pairing: in css/style.css, change the values of --font-display, --font-display-ja, --font-body, and --font-body-ja under :root to the chosen pairing's font names, then update the Google Fonts <link href="https://fonts.googleapis.com/css2?family=..."> in every page's <head> to request only those four families (to avoid loading unused font weights). No other code changes needed; every page reads type through those four variables.
